1. Creative Order

ทุกโปรเจกต์ต้องเดินตามลำดับนี้ ห้ามข้ามขั้น

1. Topic + เป้าหมาย
2. อารมณ์หลัก (Emotional Tone)
3. Story Beats
4. จังหวะ / Pacing ของแต่ละ Beat
5. Script / คำพูด
6. Visual Plan (เลือกฟุตเทจ)
7. Sound Plan
8. Edit → Grade → Motion → QA
ห้าม เริ่มจาก Script หรือเริ่มตัดภาพก่อนมี Story Beats

2. ทีม Agent

Agentหน้าที่Output
video-directorคุมทั้งกระบวนการ, spawn ลูกทีมแผน + รายงานสุดท้าย
footage-selectorเลือกฟุตเทจตาม Beat และอารมณ์Selection table

qa-reviewerตรวจคุณภาพรายงาน + คะแนน

3. มาตรฐานภาพ

  • เลือกตามความหมายและอารมณ์ของคำพูด ไม่ใช่แค่ชื่อไฟล์
  • ห้ามใช้ฟุตเทจซ้ำในคลิปเดียวกัน
  • เปลี่ยนขนาดช็อตและพลังงานตาม Beat

4. มาตรฐานเสียง

  • ใส่เฉพาะเมื่อสนับสนุนภาพ, นำทางอารมณ์, หรือสร้างจังหวะ
  • ห้าม whoosh ทุกคัท
  • ข้อความหลักเท่านั้นที่ได้เสียง accent
  • เป้าหมาย −14 LUFS, True Peak ≤ −1 dBTP
Priority เมื่อเสียงชนกัน:
1. Dialogue → 2. Motivated Foley → 3. Key Accent → 4. Transition → 5. Music → 6. Ambience

5. Checklist ก่อนส่งงาน

  • ✓ มี Story Beats ชัดเจนก่อนตัด
  • ✓ ฟุตเทจไม่ซ้ำและสนับสนุนเนื้อหา
  • ✓ เสียงผ่าน Professional Sound Logic
  • ✓ Loudness ถูกต้อง
  • ✓ มี stem และรายงาน
  • ✓ QA ผ่านเกณฑ์
